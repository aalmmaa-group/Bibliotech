# 📚 Bibliotech

O **Bibliotech** é um sistema desktop para gerenciamento da sala de leitura de uma escola, criado para facilitar o controle do acervo, empréstimos e devoluções de livros.

O sistema funciona **offline no Windows** e permite consultar a disponibilidade dos livros em tempo real.

## ✨ Funcionalidades

* 📚 Cadastro e gerenciamento de livros
* 🔄 Empréstimos, devoluções e renovações
* 🔎 Busca por título, autor e categoria
* ✅ Consulta de disponibilidade
* 📊 Relatórios e indicadores
* 💾 Backup sincronizado com Google Drive

## 🛠️ Tecnologias
